# Бот ігрових новин для Telegram

Кожні 30 хвилин бот збирає новини з чотирьох типів джерел:

- **RSS ігрових видань** (`feeds.txt`);
- **дописи з X (Twitter)** студій, платформ та інсайдерів (`x_accounts.txt`);
- **Steam** (`steam_apps.txt`): офіційні оголошення й патчі ігор, а також **зміни дати виходу** — те, що зазвичай ловлять на SteamDB;
- **Discord** (`discord_channels.txt`): оголошення офіційних серверів ігор і студій.

ШІ **оцінює важливість** кожної новини від 0 до 10 за вашими критеріями з `importance.txt` і відсіює мотлох. Решту він коротко переказує українською. Готовий пост іде в чорновий канал: картинка, заголовок, кілька речень, посилання на джерело й оцінка важливості. Вам лишається переслати потрібне в офіційний канал.

Для перекладу за замовчуванням використовується **Google Gemini**, у нього є безкоштовний тариф. Сервер не потрібен: бот працює на безкоштовному GitHub Actions.

Усі джерела англомовні або українські (GSC Game World, 4A Games, Frogwares). Жодних російських.

---

## Крок 1. Бот у Telegram (5 хв)

1. Напишіть **@BotFather** → `/newbot` → придумайте назву та юзернейм.
2. Збережіть **токен** (вигляд `123456789:AAH...`).
3. Створіть **чорновий канал** (можна приватний).
4. Додайте бота в канал **адміністратором** із правом публікувати повідомлення.

### Як дізнатись ID каналу
1. Напишіть у канал будь-яке повідомлення.
2. Відкрийте в браузері `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`.
3. Знайдіть `"chat":{"id":-100...`. Це число з мінусом і є ID каналу.

   Якщо там порожньо, напишіть у канал ще раз і оновіть сторінку.

## Крок 2. Безкоштовний ключ Gemini (3 хв)

1. Зайдіть на **aistudio.google.com** під Google-акаунтом.
2. Відкрийте **Get API key** → **Create API key**.
3. Скопіюйте ключ (починається на `AQ.` — це новий формат ключів Google, так і має бути).

Безкоштовний тариф має ліміти запитів на хвилину та на день. Актуальні цифри видно в AI Studio, у розділі *Rate limits*. Якщо ліміт вичерпано, бот почекає й спробує ще раз.

> ⚠️ На безкоштовному тарифі Google може використовувати ваші запити для навчання моделей. Для публічних новин це неважливо.

## Крок 3. Ключ для X/Twitter (5 хв, платно, але дешево)

Безкоштовного способу читати X більше немає: з лютого 2026 офіційний API коштує $0.005 за кожен прочитаний допис. Тому бот використовує сторонній сервіс **twitterapi.io**, він приблизно в 30 разів дешевший ($0.15 за 1000 дописів).

1. Зареєструйтесь на **twitterapi.io**.
2. Поповніть баланс. Кількох доларів вистачить надовго: 30 акаунтів дають приблизно 100–200 дописів на день, тобто менше $1 на місяць.
3. Скопіюйте **API key** з кабінету.

Бот щоразу бере лише нові дописи з моменту минулої перевірки, тож не платить за одне й те саме двічі.

> Якщо X не потрібен, пропустіть цей крок. Бот працюватиме лише з RSS.

## Крок 4. Discord (10 хв, необов'язково, безкоштовно)

Читати чужі сервери ботом напряму не можна: туди його має додати адміністратор, а «бот на своєму акаунті» Discord банить. Тому використовується легальна функція Discord **Follow** (підписка на канал оголошень):

1. На **своєму** Discord-сервері створіть канал `#bot-feed` і ввімкніть **«Приватний канал»**, щоб спільнота його не бачила.
2. Зайдіть на офіційні сервери ігор і студій. У каналі оголошень (значок мегафона 📢) натисніть **Follow** і виберіть свій сервер та канал `#bot-feed`. Повторіть для всіх потрібних серверів. Відтепер їхні оголошення автоматично копіюються до вас.
3. Створіть бота на **discord.com/developers/applications**:
   - **New Application**, дайте назву;
   - вкладка **Bot** → **Reset Token** → скопіюйте токен;
   - там же увімкніть **Message Content Intent** → *Save*;
   - вкладка **OAuth2 → URL Generator**: у *Scopes* поставте `bot`, у *Bot Permissions* — `View Channels` і `Read Message History`;
   - відкрийте згенероване посилання й додайте бота на свій сервер;
   - у налаштуваннях каналу `#bot-feed` → *Дозволи* додайте бота, щоб він бачив приватний канал.
4. Дізнайтесь ID каналу `#bot-feed`:
   - у Discord відкрийте *Налаштування → Розширені* і ввімкніть **Режим розробника**;
   - натисніть правою кнопкою на канал → **Копіювати ID**;
   - вставте ID у `discord_channels.txt`, наприклад `Новини ігор | 123456789012345678`.

## Крок 5. Репозиторій на GitHub (10 хв)

1. На **github.com** → **New repository**, назва, наприклад, `game-news-bot`.
   - **Public**: безлімітні безкоштовні хвилини. Ключі все одно залишаються прихованими.
   - **Private**: 2000 безкоштовних хвилин на місяць. Запуску кожні 30 хв якраз вистачає.
2. **Add file → Upload files** → перетягніть усі `.py` і `.txt` файли з архіву → *Commit changes*.
3. **Add file → Create new file**:
   - у поле назви вставте `.github/workflows/news.yml` (слеші самі створять папки);
   - вставте вміст файлу `.github/workflows/news.yml` з архіву (відкрийте його Блокнотом) → *Commit changes*.

## Крок 6. Секрети (3 хв)

У репозиторії: **Settings → Secrets and variables → Actions → New repository secret**.

| Назва | Значення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен від BotFather |
| `TELEGRAM_CHAT_ID` | ID каналу, наприклад `-1001234567890` |
| `LLM_API_KEY` | ключ Gemini (`AQ....`) |
| `X_API_KEY` | ключ twitterapi.io (необов'язково) |
| `DISCORD_BOT_TOKEN` | токен Discord-бота (необов'язково) |

## Крок 7. Запуск

**Actions** → зліва *Game news bot* → **Run workflow**.

- Через хвилину-дві в каналі з'являться 5 найсвіжіших новин. На першому запуску бот навмисно не публікує весь архів.
- Далі бот працює сам кожні 30 хвилин.
- Якщо щось не так, відкрийте запуск у вкладці Actions → крок *Run bot*. Там видно лог із помилками.

## Налаштування

### Фільтр важливості
- **`importance.txt`** містить критерії, за якими ШІ ставить оцінку 0–10. Їх можна редагувати звичайними словами: що вважати головним, а що мотлохом, кого виключити (китайські, мобільні, казуальні ігри вже виключено).
- **Поріг публікації** за замовчуванням — 5 для всіх джерел. Змінити його можна без редагування коду: *Settings → Secrets and variables → Actions → Variables*:
  - `MIN_SCORE` змінює поріг для всіх джерел одразу;
  - `MIN_SCORE_ARTICLE`, `MIN_SCORE_TWEET`, `MIN_SCORE_STEAM`, `MIN_SCORE_DISCORD` задають поріг для окремого джерела. Наприклад, `MIN_SCORE_STEAM = 7` залишить зі Steam лише великі оновлення.
- **Що відсіялося**, видно в лозі запуску (Actions → *Run bot*), рядки `пропущено` з оцінкою. Якщо бачите там щось важливе, підправте критерії або знизьте поріг.
- Перший тиждень корисно стежити за оцінками в постах (`Важливість: 7/10`) і налаштувати критерії під себе.

### Джерела
- **`feeds.txt`**: RSS, по одному в рядку, у форматі `Назва | посилання`.
- **`x_accounts.txt`**: юзернейми X, по одному в рядку. Ретвіти та відповіді бот пропускає. Якщо до допису не прикріплено фото, бот бере картинку зі сторінки, на яку посилається допис.
- **`steam_apps.txt`**: ігри Steam у форматі `Назва | ID`. ID — це число з адреси сторінки гри в Steam. Бот повідомить про нове оголошення розробників, про зміну дати виходу і про реліз гри.
- **`discord_channels.txt`**: ID каналів вашого сервера, куди ви підписали оголошення (див. крок 4).
- `#` на початку рядка вимикає джерело.
- Список у `x_accounts.txt` — стартовий. Перевірте, що всі акаунти живі, і додайте свої.

### Інша ШІ-модель
Змінюється без редагування коду: *Settings → Secrets and variables → Actions → вкладка **Variables***.

| Змінна | Значення |
|---|---|
| `LLM_PROVIDER` | `gemini` (за замовчуванням), `groq`, `openrouter` або `openai` |
| `LLM_MODEL` | конкретна модель; необов'язково, крім openrouter |

| Провайдер | Ціна | Де взяти ключ | Примітка |
|---|---|---|---|
| **gemini** | безкоштовно | aistudio.google.com | найкраща українська серед безкоштовних |
| **groq** | безкоштовно | console.groq.com | дуже швидкий; українська трохи слабша |
| **openrouter** | є безкоштовні моделі | openrouter.ai | у `LLM_MODEL` вкажіть модель з позначкою `:free` |
| **openai** | платно, ~$5–10/міс | platform.openai.com | ChatGPT |

Ключ для будь-якого провайдера кладеться в той самий секрет `LLM_API_KEY`. Якщо модель за замовчуванням недоступна, бот сам перемкнеться на запасну.

### Стиль перекладу
Тексти `ARTICLE_PROMPT` (для статей) і `TWEET_PROMPT` (для дописів з X) на початку `bot.py`. Їх можна редагувати звичайними словами.

### Частота та ліміти
- `cron: "*/30 * * * *"` у `news.yml` задає частоту запуску. GitHub іноді запускає із запізненням на 5–15 хв, це нормально.
- `MAX_POSTS_PER_RUN` (25): скільки постів максимум за один запуск.
- `MAX_AGE_HOURS` (12): новини, старші за цей час, ігноруються.
- `MAX_LLM_CALLS` (80): скільки разів за запуск можна звернутися до ШІ. Захищає безкоштовні ліміти Gemini; решта новин обробиться наступного запуску.

## Як переносити в офіційний канал
- **Переслати** пост: з'явиться позначка «переслано з…».
- Або довге натискання → **Копіювати**, вставити в офіційний канал і за потреби відредагувати. Так позначки не буде.
